# Praxis

服务地址优先使用用户提供的地址，默认 `http://127.0.0.1:4310`。

先请求 `GET /api/docs`，按返回的 OpenAPI 请求 schema 和 `x-agent-guide` 调用接口。文档与当前服务的路由及校验定义同步，以该接口为准，不依赖记忆中的参数。

通过控制 API 配置业务，不直接修改数据库、缓存、Pi 凭据或项目源码。仓库路径指服务所在机器上的路径；模型从 API 查询，业务范围与执行操作遵循用户授权。

触发后记录运行 id，查询至终态；配置冲突或请求断线时先读取当前状态，避免盲目重复写入或触发。服务不可达时，先检查目标地址和进程；有项目目录时可运行 `npm run dev` 启动。
